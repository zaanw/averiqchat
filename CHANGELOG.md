# Изменения

## 0.1.0-beta.1 — кандидат, не опубликован

- Авторизация Supabase, подтверждение email и восстановление пароля.
- Профили, уникальные юзернеймы и аватары.
- Личные чаты, группы, ответы, правки и удаление сообщений.
- Личные папки и закрепления с сохранением в базе; поиск по всей истории чата с ответом из результатов.
- Настройки оформления, сочетания клавиш отправки и видимости набора текста.
- Приватные вложения с проверкой членства и подписанными ссылками.
- Блокировки, жалобы, ограничения частоты RPC.
- Минималистичный адаптивный интерфейс, темы, фильтры чатов и меню сообщений.
- Постоянная проверка доступности сайта и публичного Supabase API через GitHub Actions.
- Unit/SQL и браузерные проверки; живые проверки включаются отдельно.

Не готово для объявления публичного релиза: собственный SMTP и доставка писем, полная приёмка на настоящих аккаунтах, проверенное восстановление резервной копии. Сквозное шифрование, звонки и push-уведомления не реализованы.
