# Самостоятельная реализация Averiq Chat

Averiq Chat — отдельный продукт на Next.js и Supabase. Он не является клиентом
или форком Telegram, не подключается к его сети и не заявляет связь с Telegram.
Привычные сценарии мессенджеров реализованы в коде этого репозитория.

В приложение не включены исходники, логотип, иллюстрации, анимации или стикеры
Telegram. Отдельная локальная экспериментальная копия Telegram Web A не является
частью этого проекта, его зависимостей или сборки GitHub Pages.

Название, знак Averiq и SVG-фон принадлежат оформлению этого проекта. Интерфейс
использует системные шрифты и Lucide; сторонние библиотеки сохраняют свои лицензии.
Лицензия собственного кода — MIT. Не удаляйте лицензии зависимостей при распространении.

Дизайн опирается на общие сценарии: список разговоров, поиск, папки, заметки,
ответы и реакции. Это не обещание полного совпадения функций или точной копии
внешнего вида другого приложения. При добавлении материалов проверяйте их
происхождение и право использования; не выдавайте Averiq за официальный Telegram.
