Averiq Chat 0.1.0-beta.1 — кандидат первой публичной беты.

Работают интерфейс, Supabase-схема и публикация GitHub Pages. Подготовлены личные чаты, группы, приватные вложения, ответы, правки, блокировки и жалобы. Локальные SQL/браузерные проверки и CI не заменяют живую приёмку.

Релиз пока оставлен черновиком. До объявления публичной беты необходимо подключить SMTP с подтверждённым доменом, проверить получение писем и сценарии разных аккаунтов, подготовить и проверить резервное копирование. Полный список условий — docs/RELEASE.md, эксплуатация — docs/OPERATIONS.md.

Сквозного шифрования, звонков, push-уведомлений и автоматической модерации нет. Этот кандидат не является стабильным production-релизом.
