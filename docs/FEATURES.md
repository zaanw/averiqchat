# Возможности Averiq Chat

Это самостоятельный мессенджер с привычными сценариями общения. Полного
совпадения возможностей Telegram нет; несуществующие функции не показаны кнопками.

В коде приложения реализованы:

- аккаунты Supabase, профили, аватары, уникальные юзернеймы;
- личные чаты и группы, история, ответы, редактирование и удаление;
- приватные изображения и документы, поиск по текстовой истории;
- папки и закрепления, личные заметки «Избранное»;
- шесть реакций, по одному эмодзи на участника;
- темы, цвет акцента, размер текста, фон, компактность и клавиши отправки;
- индикатор набора с возможностью отключения, блокировки, жалобы и выход из сессий.

«Избранное» создаётся один раз для аккаунта. В нём один участник, приглашения
не поддерживаются. Заметки и файлы сохраняются в той же базе с проверкой членства.
Это приватный чат по правилам доступа сервера, а не сквозное шифрование.

Чужие реакции появляются при обновлении истории (резервный интервал — 5 секунд).
Одна реакция заменяет предыдущую, повторный выбор снимает её. Удаление сообщения
очищает реакции в той же транзакции; выход участника удаляет его реакции в группе.

Пока не реализованы звонки, голосовые сообщения, каналы, боты, push-уведомления,
стикерпаки, пересылка и запланированная отправка. Для них потребуется отдельная
реализация и проверка, а для стикеров — собственные или лицензированные материалы.

Проверки SQL и интерфейса не заменяют приёмку на настоящих аккаунтах. Доставка
писем, полный обмен сообщениями и готовность публичного релиза описаны в README
и docs/RELEASE.md. Правила использования материалов: docs/INDEPENDENT-IMPLEMENTATION.md.
